# 🌿 Mental Health Companion

An AI-powered chatbot that helps users manage stress and emotions.

## 💡 Features
- 💬 Chat with AI (phi3 via Ollama)
- 🌟 Positive affirmations
- 🧘 Meditation guidance

## 🛠 Tech Stack
- Python
- Streamlit
- Ollama (LLM)


## ▶️ How to Run

```bash
streamlit run chatbot.py
